## After the talk

<!-- present-record-handout.png -->
### Present, record, hand out
{cards}

- A presenter view with notes and a clock
- Record the room while you present
- Transcribe what you said, slide by slide
- Publish a handout for every delivery

<!-- how-you-work.png -->
### How you work with it
{numbered}

- Write the talk as an outline
- Watch it render to slides as you type
- Tick a Pathway for each audience
- Present, record and publish
