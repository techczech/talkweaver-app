# The website

The TalkWeaver website, https://talkweaver.app, now lives in its own repository and is built and deployed from there. Nothing in this repository deploys it.

`docs/index.html` here only forwards visitors who arrive at the old GitHub Pages address (`techczech.github.io/talkweaver-app`) to talkweaver.app. The rest of `docs/` holds test fixtures used by the test suite. Do not deploy `docs/` anywhere.
