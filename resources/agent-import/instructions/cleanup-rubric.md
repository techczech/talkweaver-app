# Import cleanup rubric

## Structural parity

- Preserve every source text item unless the selected pass explicitly permits editorial rewriting.
- Preserve the source order where it carries meaning.
- Report missing or duplicated text, media and speaker notes.
- Keep the original render as the effective representation when unsupported content has no faithful native equivalent.

## Layout repair

- Prefer TalkWeaver's native statement, list, media and copy-visual structures when source evidence supports them.
- Treat grouping, hierarchy and image-copy relationships as interpretive decisions.
- Explain each interpretive decision in `rationale` and name the evidence files used.

## Accessibility

- Describe meaningful visual content from the original render and source evidence.
- Do not invent facts that are not visible or present in the source.

## Editorial work

- Rewrite only when `editorial` appears in the selected passes.
- Mark editorial suggestions as `sourcePreserving: false`.
