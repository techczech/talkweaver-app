# What's new in 0.45.0-alpha.1

- **Where a recording is.** Studio, the recording panel and the Runs view say which Mac holds a recording, instead of saying a file is missing.
- **Sync conflicts named.** iCloud and Syncthing conflict copies are recognised, and a Git conflict in a recording, Pathways or Notes file is named with its file. TalkWeaver never saves over a file it cannot read.
- **Recording edits on two Macs.** The edits name the Mac and version that saved them. When two Macs change them, both versions are kept, and Kept edits lists, opens and restores the copies.
- **Presenter preview keeps step** with the audience on loop slides and contents strips, and an exported video no longer starts with a "Slide" chapter.
