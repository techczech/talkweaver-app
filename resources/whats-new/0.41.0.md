# What's new in 0.41.0

- **Pre-work and post-work.** Work files in your vault hold the steps; a Run sends them. The Tools window has three new views: Sessions, Published pages and Work files.
- **Plan a run.** Choose the slides, a pre-work block and a post-work block for one session, and copy an earlier Run with Plan the next run like this.
- **Publish for this run.** One command puts up the handout, the pre-work page and the post-work page, with the links and a QR code.
- **Image drawer.** Command-Shift-I opens a drawer beside the editor with SlideWell, PowerPoint imports and the pictures already in your talks.
- **Undo after a save.** One Command-Z takes back a save's tidy-up together with your edit.
- **Redrawn slide layouts.** Icons on list items and boxes, centred content and numbered process slides.
