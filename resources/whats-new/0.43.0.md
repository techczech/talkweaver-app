# What's new in 0.43.0

- **Rich editor.** Edit text and formatting directly. The outline stays the saved source. Image editing and the image drawer sit alongside it.
- **Vault Gallery.** Browse talks and files, with views of published handouts and stored results. Offline copies. Keep offline copies of captured web pages.
- **Publish one talk.** Publishing updates the selected talk and keeps the other talks already on the site. Agent skill. Install TalkWeaver's agent skill for supported tools.
- **Large talks.** They open and navigate with less repeated compilation and thumbnail work, and keep your current slide and place. Recordings. A recording recovered after a crash keeps its audio. Empty recording segments no longer block transcription.
- **Animated video in Studio.** Assemble an animated video from a recorded Run. A finished video package now shows as ready even when macOS fails to report the file change.
- **Choose the microphone.** Pick it in Settings. The choice is remembered on this Mac. If the microphone drops out. The notice says nothing is being recorded and offers another connected microphone by name.
- **Consistent names.** Scratchpad, slide controls, Pathways and Run navigation use the same wording. The Mac app menu and About panel use the TalkWeaver name.
- **Security.** TalkWeaver now ignores the NODE_OPTIONS environment variable and Node debugging flags when it starts. On Mac, it no longer allows DYLD library injection, unsigned libraries or unsigned executable memory. Further hardening is planned.
