# What's new in 0.45.0-alpha.3

- **Settings that follow you between Macs.** Settings › Set-up folder: choose a folder that syncs between your Macs. Each Mac keeps its own file there.
- **See before you apply.** On a second Mac, a preview shows what will change. Later changes arrive by themselves, listed with the Mac they came from and an Undo.
- **Where you publish.** The publishing account, site and branch, and the handout and share-link addresses from another Mac, are offered with Use on this Mac.
- **What travels and what stays.** 52 settings travel: preferences, shortcuts, the publishing site, each vault's author and badge. Keys, tokens, folder locations, microphone and camera, the call to action, credits and the logo stay on each Mac.
