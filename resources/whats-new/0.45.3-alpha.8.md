# What's new in 0.45.3-alpha.8

- If publishing fails, TalkWeaver tells you what went wrong and whether the live site changed.
- Uploads can carry on over slow connections and pick up again after a connection drops.
- Agents can publish handouts from the command line with `talkweaver publish`.
- A failed publish stays visible so you can try again or copy the details.
- When an outline changes on disk, review the changes slide by slide before merging them.
